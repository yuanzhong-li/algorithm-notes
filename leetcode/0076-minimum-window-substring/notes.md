# 76. 最小覆盖子串（Minimum Window Substring）

- 难度：困难
- 标签：哈希表、字符串、滑动窗口
- 链接：https://leetcode.cn/problems/minimum-window-substring/

## 题目

给定字符串 `s`、`t`，在 `s` 中找出**覆盖 `t` 所有字符**的最短子串（`t` 中重复字符也要覆盖够次数）。  
若不存在，返回空串 `""`。题目保证答案唯一。

## 例子

输入：`s = "ADOBECODEBANC"`，`t = "ABC"`  
输出：`"BANC"`  
（包含 A、B、C 的最短子串）

## 思路（可变长度滑动窗口）

和 438「找异位词」很像，都是看窗口里字符够不够；差别是：

| 题 | 窗口要求 | 窗口长度 |
|----|----------|----------|
| 438 异位词 | 计数和 `p` **完全一样** | 固定 = `p.size()` |
| **76 最小覆盖** | 计数**至少覆盖** `t`（可以多） | 可变，要最短 |

套路：

1. **右指针扩张**：直到窗口「覆盖」了 `t`（每种需要的字符数量都 ≥ 要求）
2. **左指针收缩**：在仍然覆盖的前提下尽量缩短，并记录最短窗口
3. 左端再挪一下导致不覆盖了 → 继续右扩，重复

用两个哈希表：

- `need`：`t` 里每个字符要几个
- `window`：当前窗口里相关字符有几个

再用 `valid` 记：已经「凑齐」的字符种类数。  
当 `valid == need 的种类数` 时，窗口合法。

### `need` 和 `window` 里到底是什么？

可以想成两本记账本，专门记 **字符 → 出现次数**。

**`need`：购物清单（固定不变）**

对 `t = "ABC"`，读完 `t` 后：

```text
need = {
  'A': 1,
  'B': 1,
  'C': 1
}
```

意思：窗口里至少要有 1 个 A、1 个 B、1 个 C。  
若 `t = "AABC"`，则 `'A': 2`。  
`need` 建好后**不再修改**。

**`window`：购物车（随窗口滑动变化）**

一开始是空的 `{}`。  
右扩到窗口 `"ADOBEC"` 时（只关心 t 里的字母）：

```text
window = {
  'A': 1,
  'B': 1,
  'C': 1
}
```

此时每种都达到 `need`，窗口合法。  
允许多：比如 `'A': 2` 也没问题（覆盖可以多，不能少）。

| | 含义 |
|--|------|
| `need[c]` | 字符 c **至少要几个** |
| `window[c]` | 窗口里 c **现在有几个** |

`window[c] >= need[c]` → 这种字符够了。  
`valid` 在「从不够变成刚好够」时 +1，用来快速判断是否全部凑齐。

### 为什么用 `unordered_map`？

我们要的是：给定字符 `c`，马上知道它需要几个 / 窗口里有几个 → **用字符当 key 查次数**。

| 结构 | 适合场景 |
|------|----------|
| `vector<int>(26)` | 只有小写 a–z（438 异位词那样） |
| `unordered_set` | 只问「有没有」，**不记个数** → 这题不行（`t="AABC"` 要 2 个 A） |
| **`unordered_map<char,int>`** | 大小写都有、按字符计数，最通用 |

76 的例子是大写字母，用长度 26 的小写数组不方便；map 来什么字符存什么。  
`unordered_map` 是哈希表，查/改平均 O(1)，所以整题能做到约 O(\|s\|)。

本质：`need` / `window` 都是「字符 → 次数」表；选 map 是为了通用和写法简单。

### 走一遍例子（示意）

`s = "ADOBECODEBANC"`，`t = "ABC"`  
`need`: A=1, B=1, C=1，种类 3

右扩到第一次覆盖，例如窗口包含到第一个 `"ADOBEC"`（下标 0~5），合法。  
然后左缩：丢掉用不需要的 / 多余的，尽量变短；不够覆盖就停，再右扩……

过程中会遇到更短的合法窗口，最终最短是 `"BANC"`。

## 代码对应

```cpp
if (window[c] == need[c]) ++valid;  // 某字符刚好凑齐一种
```

注意是 `==` 不是 `>=`：只在「从不够变成刚好够」时 +1，避免重复加。

```cpp
while (valid == needKinds) { ... 缩左端 ... }
```

合法就缩；缩到某字符不够时 `valid--`，退出 while，继续右扩。

```cpp
return minLen == INT_MAX ? "" : s.substr(start, minLen);
```

从未找到合法窗口 → 返回 `""`。

## 复杂度

- 时间：O(|s| + |t|)，每个下标最多进、出窗口一次
- 空间：O(|字符集|)，哈希表大小

## 感想 / 踩坑

- 「覆盖」允许窗口里多出其他字符，也允许多余的目标字符；只要每种都 ≥ `need`
- 和异位词不同：不用 `window == need`，因为可以多
- `valid` 用「刚好凑齐」时增减，逻辑更稳
- 要记最短子串的**起点 + 长度**，最后再 `substr`
