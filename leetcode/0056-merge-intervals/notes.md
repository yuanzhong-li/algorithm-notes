# 56. 合并区间（Merge Intervals）

- 难度：中等
- 标签：数组、排序
- 链接：https://leetcode.cn/problems/merge-intervals/

## 题目

给定若干区间 `intervals`，其中 `intervals[i] = [start_i, end_i]`。  
合并所有重叠的区间，返回一个不重叠、又覆盖所有输入区间的数组。

重叠：两个区间有交集，或一个碰到另一个的端点（如 `[1,4]` 和 `[4,5]` 应合并成 `[1,5]`）。

## 例子

输入：`intervals = [[1,3],[2,6],[8,10],[15,18]]`  
输出：`[[1,6],[8,10],[15,18]]`  
解释：`[1,3]` 与 `[2,6]` 重叠，合并为 `[1,6]`。

## 思路（排序 + 一次扫描）

乱序时很难判断谁和谁重叠。先按**起点从小到大**排序，再从左到右合并。

排序后相邻才可能重叠（或通过连续合并间接重叠）。

维护结果数组 `ans`，其中最后一段 `ans.back()` 是「当前正在合并的区间」：

1. 下一个区间起点 `<= ans.back() 的终点` → **有重叠**（或刚好接上）  
   → 把 `ans.back() 的终点` 更新为两者终点的较大值
2. 否则 → **无重叠**，把这个区间作为新的一段推进 `ans`

### 走一遍例子

输入：`[[1,3],[2,6],[8,10],[15,18]]`  
排序后起点已有序（本例本来就有序）。

| 处理区间 | ans 变化 | 原因 |
|----------|----------|------|
| `[1,3]` | `[[1,3]]` | 第一段直接放入 |
| `[2,6]` | `[[1,6]]` | 2 ≤ 3，重叠，右端变成 max(3,6)=6 |
| `[8,10]` | `[[1,6],[8,10]]` | 8 > 6，不重叠，新开一段 |
| `[15,18]` | `[[1,6],[8,10],[15,18]]` | 15 > 10，新开一段 |

答案：`[[1,6],[8,10],[15,18]]`

### 再看一个端点相接的例子

`[[1,4],[4,5]]` → `4 <= 4`，合并为 `[[1,5]]`。

## 代码对应

```cpp
sort(..., a[0] < b[0]);  // 按起点排序
```

```cpp
if (intervals[i][0] <= ans.back()[1]) {
    ans.back()[1] = max(ans.back()[1], intervals[i][1]);
} else {
    ans.push_back(intervals[i]);
}
```

有重叠就拉长右端；没有就新开一段。

```cpp

输入/输出都是「一堆区间」，每个区间两个数 `[起点, 终点]`，所以是 `vector<vector<int>>`。

```

没有区间就返回空。`{}` 表示空的 `vector`。

```cpp

             return a[0] < b[0];
         });
```

按**起点从小到大**排序。  
后面的 `[](a, b) { return a[0] < b[0]; }` 是比较规则：谁的 `a[0]` 更小谁在前。

```cpp

    ans.push_back(intervals[0]);
```

准备结果数组，先把排序后第一个区间放进去（还没有「上一段」可合并）。

### `ans.back()` 是什么？

`back()` = 取出 `vector` **最后一个元素**。

```text
ans = [ [1,3], [8,10] ]
                 ↑
            ans.back() → [8,10]
ans.back()[0] → 起点 8
ans.back()[1] → 终点 10
```

这题里 `ans.back()` 就是「已经合并好的最后一段」，也就是接下来拿来和新区间比较的那段。  
它和 `ans[ans.size() - 1]` 意思相同，写法更短。

```cpp
    for (int i = 1; i < (int)intervals.size(); ++i) {
```

从第 2 个区间（下标 1）开始扫。

```cpp
        if (intervals[i][0] <= ans.back()[1]) {
```

| 写法 | 含义 |
|------|------|
| `intervals[i][0]` | 当前区间的起点 |
| `ans.back()[1]` | 结果里最后一段的终点 |

当前起点 `<=` 最后一段终点 → 有重叠或端点相接 → 要合并。

```cpp
            ans.back()[1] = max(ans.back()[1], intervals[i][1]);
```

有重叠：只改最后一段的终点，取两者终点的较大值。  
用 `max` 是因为新区间可能被完全包住（如 `[1,10]` 再来 `[2,3]`，终点仍应是 10）。

```cpp
        } else {
            ans.push_back(intervals[i]);
        }
```

没重叠：当前区间作为新的一段加到 `ans` 末尾。

```cpp
    }
    return ans;
```

扫完返回合并结果。

### 用例子串一遍

输入：`[[1,3],[2,6],[8,10],[15,18]]`

1. 排序（本例已有序）
2. `ans = [[1,3]]`
3. `[2,6]`：`2 <= 3` → 合并 → `ans = [[1,6]]`
4. `[8,10]`：`8 > 6` → 新开 → `ans = [[1,6],[8,10]]`
5. `[15,18]`：`15 > 10` → 新开 → `ans = [[1,6],[8,10],[15,18]]`

## 复杂度

- 时间：O(n log n)，主要花在排序；后面扫描 O(n)
- 空间：O(log n) 或 O(n)，取决于排序实现；答案数组另计

## 感想 / 踩坑

- 先排序是关键，否则不好线性合并
- 判断重叠用 `<=`（端点相等也算重叠/可合并）
- 合并时右端取 `max`，因为新区间可能被完全包在旧区间里面（如 `[1,10]` 再来 `[2,3]`）
- `ans.back()` = 结果里最后一段；能重叠就改它的右端点，不能就 `push_back` 新区间
