# 234. 回文链表（Palindrome Linked List）

- 难度：简单
- 标签：链表、双指针、栈、递归
- 链接：https://leetcode.cn/problems/palindrome-linked-list/

## 题目

给定单链表头节点 `head`，判断是否为回文链表。是则返回 `true`，否则 `false`。

回文：正着读和反着读一样，如 `1 -> 2 -> 2 -> 1`。

## 例子

输入：`[1,2,2,1]` → `true`  
输入：`[1,2]` → `false`

## 思路（找中点 + 反转后半 + 比较）

链表不能像数组那样直接从两端往中间比（没有前驱指针）。

标准 O(n) 时间、O(1) 空间做法：

1. **快慢指针找中点**  
   - `fast` 一次走两步，`slow` 一次走一步  
   - `fast` 到末尾时，`slow` 在前半段最后一个节点

2. **反转后半段**（和 206 反转链表一样）  
   - 从 `slow->next` 开始反转

3. **前后两半逐个比 `val`**  
   - 有一个不相等就不是回文

4. （可选）再把后半段反转回来，恢复原链表

### 走一遍例子

`1 -> 2 -> 2 -> 1`

```text
找中点后：slow 在第一个 2
前半：1 -> 2
后半：2 -> 1  反转后变成 1 -> 2

比较：1==1，2==2 → true
```

奇数长度如 `1 -> 2 -> 3 -> 2 -> 1`：中间的 `3` 不用比，后半从 `3` 后面开始即可。

### 和其他做法

| 做法 | 空间 | 好不好懂 |
|------|------|----------|
| **官方：拷进数组再双指针** | O(n) | 很短、很好懂 |
| 栈 | O(n) | 一般 |
| 找中点 + 反转 | O(1) | 稍绕，省空间 |

## 官方解法（数组 + 两端比较）

链表不好从尾巴往回走，所以先变成数组，再按回文常规方法检查：

```cpp
bool isPalindrome(ListNode* head) {
    vector<int> vals;
    while (head != nullptr) {
        vals.emplace_back(head->val);  // 把值加到数组末尾
        head = head->next;
    }
    for (int i = 0, j = (int)vals.size() - 1; i < j; ++i, --j) {
        if (vals[i] != vals[j]) return false;
    }
    return true;
}
```

为什么对：链表是回文 ⇔ 节点值序列是回文 ⇔ `vals` 数组是回文。

### `emplace_back` 是什么？

`vals.emplace_back(head->val)` = 把 `head->val` 放到 `vals` 末尾。  
这题里和 `push_back(head->val)` 效果一样。

## 和 206 的关系

O(1) 空间写法里，后半段反转直接复用「反转链表」的三指针。

## 复杂度

- 找中点 + 反转：时间 O(n)，额外空间 O(1)
- 官方数组写法：时间 O(n)，额外空间 O(n)

## 感想 / 踩坑

- 求好懂、能过题 → 官方数组写法完全够用
- 面试强调 O(1) 空间 → 用找中点 + 反转
- 快慢指针条件写成 `fast->next && fast->next->next`，让 slow 停在前半末尾
- 注意空链表、单节点是回文
