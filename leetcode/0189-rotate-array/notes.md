# 189. 轮转数组（Rotate Array）

- 难度：中等
- 标签：数组、数学、双指针
- 链接：https://leetcode.cn/problems/rotate-array/

## 题目

给定数组 `nums`，将数组中的元素向右轮转 `k` 个位置，`k` 为非负数。  
要求尽量**原地**修改（空间 O(1) 更佳）。

## 例子

输入：`nums = [1,2,3,4,5,6,7]`，`k = 3`  
输出：`[5,6,7,1,2,3,4]`

向右转 1 步：`[7,1,2,3,4,5,6]`  
向右转 2 步：`[6,7,1,2,3,4,5]`  
向右转 3 步：`[5,6,7,1,2,3,4]`

## 思路（三次反转）

观察目标：右边 `k` 个数跑到最前面，原来的前面挪到后面。

把数组看成两段：

```text
A = 前 n-k 个
B = 后 k 个
原来 = A + B
目标 = B + A   （两段换位置，各自内部顺序不变）
```

例如 `[1,2,3,4,5,6,7]`，`k=3`：

```text
A = [1,2,3,4]
B = [5,6,7]
目标 = [5,6,7,1,2,3,4]
```

有个巧妙办法——**反转三次**：先让两段换边，再把每段内部顺序掰正。

### 三步分别是什么意思

**第 ① 步：整体反转**

```text
原来：  1 2 3 4 | 5 6 7
       ----A----  --B--

整体翻： 7 6 5 | 4 3 2 1
         --B反--  ---A反---
```

效果：`A`、`B` 换边了（B 到左边），但两段内部都是反的。  
人话：先把「后 k 个」整块搬到前面，顺序暂时反着，后面再修。

**第 ② 步：只反转前 k 个**

```text
翻前 3 个：  5 6 7 | 4 3 2 1
            --B正--  ---A反---
```

效果：左边的 B 顺序掰正了。  
人话：把已经搬到前面的那 k 个数，翻回正确顺序。

**第 ③ 步：反转后面剩下的**

```text
翻后面：  5 6 7 | 1 2 3 4
         --B正--  ---A正---
```

效果：右边的 A 也掰正了，得到目标。  
人话：把挪到后面的那一段，也翻回正确顺序。

### 三步对照表

| 步骤 | 做什么 | 目的 |
|------|--------|------|
| ① 整体反转 | 整段翻个面 | 后 k 个跑到前面（顺序暂反） |
| ② 翻前 k 个 | 只修左边 | 前面那块顺序变对 |
| ③ 翻后面 | 只修右边 | 后面那块顺序变对 |

公式记忆：

```text
目标 = B + A
① 变成：  B反 + A反
② 变成：  B   + A反
③ 变成：  B   + A      ← 完成
```

### 为什么要先 `k %= n`？

转 `n` 步等于转回原样。  
若 `k = 10`，`n = 7`，实际效果和 `k = 3` 一样，所以先取模。

## 代码对应

```cpp
k %= n;
if (k == 0) return;
```

去掉整圈，若不用转直接返回。

```cpp
reverse(nums.begin(), nums.end());
reverse(nums.begin(), nums.begin() + k);
reverse(nums.begin() + k, nums.end());
```

三次 `reverse`。`reverse(起始, 结束)` 翻的是 **[起始, 结束)** 半开区间。

## 另一种写法（额外数组，更好懂但多用空间）

```cpp
vector<int> tmp(n);
for (int i = 0; i < n; ++i) {
    tmp[(i + k) % n] = nums[i];
}
nums = tmp;
```

每个数移到新下标 `(i+k)%n`。清晰，但空间 O(n)。

## 复杂度（三次反转）

- 时间：O(n)
- 空间：O(1) 额外空间

## 感想 / 踩坑

- 别忘了 `k %= n`，否则 `k` 很大时会越界或逻辑错
- 右旋 k = 左旋 n-k，本质类似
- `reverse` 的区间是左闭右开：`[begin, begin+k)` 正好是前 k 个
