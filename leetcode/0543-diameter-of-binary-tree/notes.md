# 543. 二叉树的直径（Diameter of Binary Tree）

- 难度：简单
- 标签：树、深度优先搜索、二叉树
- 链接：https://leetcode.cn/problems/diameter-of-binary-tree/

## 题目

给定二叉树根节点，返回该树的**直径**。

直径：任意两个节点之间最长路径的长度。  
这条路径**不一定过根**。  
长度按**边的条数**计算（不是节点个数）。

## 例子

```text
      1
     / \
    2   3
   / \
  4   5
```

最长路径如 `4→2→1→3` 或 `5→2→1→3`，有 3 条边 → 直径 `3`。

注意：

- 数的是**边**，不是节点（这条路有 4 个点，但是 3 条边）
- 最长路径不一定经过根

## 思路（每个节点都可能是「拐点」）

任意一条路径，从一端走到另一端，总会经过一个「最高」的节点（路径上最靠近根的那个），叫它**拐点**。

路径形状一定是：

```text
从拐点的左子树爬上来 → 经过拐点 → 再下到右子树
```

（也可能只走一边，另一边高度为 0。）

所以对节点 `node`：

```text
经过 node 的最长路径边数 = 左子树高度 + 右子树高度
```

整棵树直径 = **对每一个节点都算一遍「左高+右高」，取最大值**。

### 高度在代码里怎么定义？

```text
depth(空) = 0
depth(node) = max(depth(左), depth(右)) + 1
```

叶子：`max(0,0)+1 = 1`。  
对父节点，`L`、`R` 表示左右子树往下能走多深，于是：

```text
L + R = 左边最深到 node 的边数 + node 到右边最深的边数
      = 经过 node 的「左右贯通」路径边数
```

### 走一遍例子

```text
      1
     / \
    2   3
   / \
  4   5
```

| 节点 | L | R | L+R（更新 ans） | 返回 depth |
|------|---|---|-----------------|------------|
| 4,5,3（叶） | 0 | 0 | 0 | 1 |
| 2 | 1 | 1 | 2（路径 4-2-5） | 2 |
| 1 | 2 | 1 | 3（路径 4-2-1-3） | 3 |

最终 `ans = 3`。在节点 2 和 1 都试过「经过自己的最长路」，取最大即直径。

### 和 104 最大深度的关系

| 题 | 求什么 |
|----|--------|
| 104 最大深度 | 从根往下最深多少（节点数） |
| **543 直径** | 整棵树里最长的一条路（边数） |

都要算左右子树深度；543 多一步：每个节点用 `左+右` 更新全局最大。  
104 只从根往下看；543 要在**每个节点**都当一次拐点来试。

## 代码逐行讲解

```cpp
int ans;  // 全局最大直径（边数）

int depth(TreeNode* node) {
    if (node == nullptr) return 0;   // 空，高度 0

    int L = depth(node->left);       // 左子树高度
    int R = depth(node->right);      // 右子树高度

    ans = max(ans, L + R);           // 用「经过本节点」的路径更新答案

    return max(L, R) + 1;            // 返回本节点高度，给父节点用
}
```

- `depth` 的**返回值**：给上面用的「我有多高」  
- `ans` 的**更新**：顺便记下「经过我的路有多长」  

一个函数干两件事，一遍 DFS 就够了。

## 复杂度

- 时间：O(n)
- 空间：O(h)

## 感想 / 踩坑

- 直径是**边数**，不是节点数；路径 `A-B-C` 直径是 2
- 最长路径未必过根，所以每个节点都要更新 `ans`
- 别只返回 `depth(root)`，那只是高度，不是直径

### 一句话记住

> 直径 = 所有节点上「左子树高 + 右子树高」的最大值；  
> DFS 一边算高度，一边用 `L+R` 更新这个最大值。
