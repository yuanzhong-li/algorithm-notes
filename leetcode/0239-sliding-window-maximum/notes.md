# 239. 滑动窗口最大值（Sliding Window Maximum）

- 难度：困难
- 标签：队列、数组、滑动窗口、单调队列、堆（优先队列）
- 链接：https://leetcode.cn/problems/sliding-window-maximum/

## 题目

给定数组 `nums` 和滑动窗口大小 `k`。窗口从最左滑到最右，每次右移一位。  
返回每个窗口中的**最大值**。

## 例子

输入：`nums = [1,3,-1,-3,5,3,6,7]`，`k = 3`  
输出：`[3,3,5,5,6,7]`

| 窗口 | 最大值 |
|------|--------|
| `[1,3,-1]` | 3 |
| `[3,-1,-3]` | 3 |
| `[-1,-3,5]` | 5 |
| `[-3,5,3]` | 5 |
| `[5,3,6]` | 6 |
| `[3,6,7]` | 7 |

## 为什么不能「每 k 个枚举」找最大值？

可以枚举，而且**答案是对的**：

```text
窗口1: 看 nums[0..k-1]，找 max
窗口2: 看 nums[1..k]，找 max
...
```

问题不在对错，而在**速度**：

- 大约有 `n - k + 1` 个窗口，每个窗口要看 `k` 个数
- 总复杂度 **O(n × k)**
- `n`、`k` 到 `10⁵` 量级时会超时

窗口每次只移动一格，中间大部分元素是重复的；暴力却每次都重新扫一遍，浪费了。

单调队列就是为了**复用上一窗口的信息**：每个下标最多进队、出队各一次 → **O(n)**。

| 做法 | 结果 | 速度 |
|------|------|------|
| 每 k 个枚举找 max | 对 | O(nk)，大数据超时 |
| 单调队列 | 对 | O(n) |

前面几题滑动窗口维护的是「集合」或「计数」；  
这题要维护**最大值**，且最大值可能滑出窗口失效，所以用单调队列。

## 思路（单调递减队列）

队列里存的是**下标**（不是直接存数值），并且保证：

```text
对应的数值从队头到队尾：从大到小
队头 = 当前窗口最大值的下标
```

每次 `i` 作为窗口右端时做三件事：

1. **维护单调**：从队尾弹出所有 `nums[下标] <= nums[i]` 的下标  
   （它们既更小又更靠左，以后不可能当最大值）
2. **把 i 入队**
3. **弹出过期**：若队头下标 `<= i - k`，说明已经滑出窗口，从队头删掉
4. 当 `i >= k - 1`（窗口已满），`nums[dq.front()]` 就是当前窗口最大值

### 和前面滑动窗口题的关系

| 题 | 窗口维护什么 |
|----|----------------|
| 3 无重复最长子串 | 字符集合（有无重复） |
| 438 异位词 | 字母计数 |
| **239 窗口最大值** | 单调队列（谁最大） |

都是窗口在滑；这题多了一个「单调队列」工具。

### 走一遍例子

`nums = [1,3,-1,-3,5,3,6,7]`，`k = 3`  
`dq` 里写「下标(值)」方便看。

| i | nums[i] | 操作后 dq | 窗口满？ | 输出 |
|---|---------|-----------|----------|------|
| 0 | 1 | `0(1)` | 否 | |
| 1 | 3 | `1(3)`（1 比 1 大，弹出 0） | 否 | |
| 2 | -1 | `1(3), 2(-1)` | 是 | 3 |
| 3 | -3 | `1(3), 2(-1), 3(-3)`；队头 1 未过期 | 是 | 3 |
| 4 | 5 | 弹出更小的；`4(5)`；队头 1 过期已在前面处理… 实际：先弹队尾小于等于 5 的，再检查过期 | 是 | 5 |
| 5 | 3 | `4(5), 5(3)` | 是 | 5 |
| 6 | 6 | `6(6)` | 是 | 6 |
| 7 | 7 | `7(7)` | 是 | 7 |

答案：`[3,3,5,5,6,7]`

## 代码对应关系

```cpp
deque<int> dq;  // 存下标，值单调递减
```

- `dq.front()`：当前最大
- `dq.back()`：队尾，用来和新来的比大小

```cpp
while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();
dq.push_back(i);
```

新来的更大（或相等），旧的更小的全从队尾扔掉。

```cpp
if (dq.front() <= i - k) dq.pop_front();
```

最大值已经不在窗口里了，从队头丢掉。

```cpp
if (i >= k - 1) ans.push_back(nums[dq.front()]);
```

窗口形成后，每次记录队头对应的值。

## 复杂度

- 时间：O(n)，每个下标最多入队、出队各一次
- 空间：O(k)，队列里最多约 k 个下标

## 感想 / 踩坑

- 队列里存**下标**，方便判断是否滑出窗口（`i - k`）
- 弹出条件用 `<=`：相等的旧值也可以弹，反正同值留最新的就行
- `deque` 是双端队列：头尾都能删，这题队头删过期、队尾删更小的
