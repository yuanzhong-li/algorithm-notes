# 2. 两数相加（Add Two Numbers）

- 难度：中等
- 标签：递归、链表、数学
- 链接：https://leetcode.cn/problems/add-two-numbers/

## 题目

两个非空链表表示两个非负整数，位数**按逆序**存储，每个节点存一位数字。  
将两数相加，同样以逆序链表形式返回和。

除数字 0 外，两数都不含前导零。

## 例子

```text
l1: 2 → 4 → 3    表示 342
l2: 5 → 6 → 4    表示 465
和： 7 → 0 → 8    表示 807
```

因为是逆序存的，链表从头到尾正好是「从低位加到高位」，和竖式加法一致。

## 思路（模拟竖式加法）

从低位往高位加，维护进位 `carry`：

1. 当前位：`sum = (l1 的值，没有当 0) + (l2 的值，没有当 0) + carry`
2. 新节点的值：`sum % 10`
3. 新进位：`sum / 10`
4. 两条链表谁还有下一位就继续；最后如果还有进位，再补一个节点

用虚拟头 `dummy` + `tail` 往后面接新节点，和合并有序链表类似。

### 走一遍例子

`2→4→3` + `5→6→4`

| 步 | l1 | l2 | carry入 | sum | 写入 | carry出 |
|----|----|----|---------|-----|------|---------|
| 1 | 2 | 5 | 0 | 7 | 7 | 0 |
| 2 | 4 | 6 | 0 | 10 | 0 | 1 |
| 3 | 3 | 4 | 1 | 8 | 8 | 0 |

结果：`7→0→8`

### 注意长度不同 / 最后还有进位

例如 `9→9` + `1`：

```text
9+1=10 → 写 0，进位 1
9+0+1=10 → 写 0，进位 1
还剩进位 1 → 再写 1
结果：0→0→1（即 99+1=100）
```

所以循环条件要写成：`l1 非空 或 l2 非空 或 carry 非 0`。

## 代码逐行讲解

```cpp
ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
```

函数入口：传入两条链表的头，返回表示「和」的新链表头。

```cpp
    ListNode dummy(0);
    ListNode* tail = &dummy;
```

- `dummy`：虚拟头节点，本身不表示数字，只是方便往后面接节点  
- `tail`：指向当前结果链表的最后一个节点，一开始指向 `dummy`  
真正答案的头是 `dummy.next`。

```cpp
    int carry = 0;
```

`carry` 是进位。例如 `4+6=10`，这一位写 `0`，进位变成 `1`，留给下一位。

```cpp
    while (l1 != nullptr || l2 != nullptr || carry != 0) {
```

只要下面三种情况还有一种成立，就要继续算下一位：

1. `l1` 还有节点  
2. `l2` 还有节点  
3. 还有进位没消化完（例如最后 `99+1` 会多出一位 `1`）

```cpp
        int sum = carry;
```

当前这一位先从「上一轮的进位」算起。

```cpp
        if (l1 != nullptr) {
            sum += l1->val;
            l1 = l1->next;
        }
```

如果 `l1` 这一位还有数，加进 `sum`，然后 `l1` 走到下一位。  
没有就当加 `0`，什么都不做。

```cpp
        if (l2 != nullptr) {
            sum += l2->val;
            l2 = l2->next;
        }
```

对 `l2` 同样处理。

```cpp
        carry = sum / 10;
```

新的进位：总和的「十位」。  
例如 `sum=10` → `carry=1`；`sum=7` → `carry=0`。

```cpp
        tail->next = new ListNode(sum % 10);
```

当前位要写入的数字是个位：`sum % 10`。  
`new` 一个新节点，接到 `tail` 后面。

```cpp
        tail = tail->next;
```

`tail` 移到刚接上的这个新节点，方便下一轮继续往后面接。

```cpp
    }
    return dummy.next;
```

循环结束，返回虚拟头后面的第一个节点，就是答案链表的头。

### 对照例子再看一遍

`l1=2→4→3`，`l2=5→6→4`

| 轮次 | sum 怎么来 | 写入 | carry | 结果链表 |
|------|------------|------|-------|----------|
| 1 | 0+2+5=7 | 7 | 0 | dummy→7 |
| 2 | 0+4+6=10 | 0 | 1 | dummy→7→0 |
| 3 | 1+3+4=8 | 8 | 0 | dummy→7→0→8 |

返回 `dummy.next` → `7→0→8`。

## 复杂度

- 时间：O(max(m, n))
- 空间：O(1) 额外空间（不计答案链表）

## 感想 / 踩坑

- 逆序存储正好方便从低位加，不必先反转
- 别忘了最后可能多出一位进位
- 某条链表先走完时，另一条继续加（加上进位）即可
- 和 21 合并链表一样可用虚拟头简化「接节点」
