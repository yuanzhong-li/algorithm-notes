# 226. 翻转二叉树（Invert Binary Tree）

- 难度：简单
- 标签：树、深度优先搜索、广度优先搜索、二叉树
- 链接：https://leetcode.cn/problems/invert-binary-tree/

## 题目

给定二叉树根节点 `root`，翻转这棵二叉树，并返回根节点。

翻转：每个节点的左右孩子互换（整棵树像照镜子）。

## 例子

```text
原树：          翻转后：
      4               4
     / \             / \
    2   7           7   2
   / \ / \         / \ / \
  1  3 6  9       9  6 3  1
```

输入：`[4,2,7,1,3,6,9]`  
输出：`[4,7,2,9,6,3,1]`

## 思路（递归）

对每个节点做同一件事：

1. 把 `left` 和 `right` **交换**
2. 再递归去翻转左子树、右子树

空节点直接返回。

也可以先递归翻转左右子树，再交换；顺序不同，结果一样。

### 和最大深度的关系

104 最大深度：递归进左右，算数值。  
226 翻转：递归进左右，改结构（交换指针）。

都是「对每个节点递归处理左右孩子」的模板。

### 走一遍（示意）

在根 4：交换后左变 7、右变 2；  
再分别翻转以 7、2 为根的子树（它们内部也左右互换）……  
整棵树就镜像过来了。

## 代码

```cpp
TreeNode* invertTree(TreeNode* root) {
    if (!root) return nullptr;
    swap(root->left, root->right);  // 或手写三行交换
    invertTree(root->left);
    invertTree(root->right);
    return root;
}
```

## 复杂度

- 时间：O(n)，每个节点访问一次
- 空间：O(h)，递归栈

## 感想 / 踩坑

- 交换的是指针（孩子节点），不是节点里的 val
- 记得处理空树
- 这题很经典，面试常用来开场考递归
