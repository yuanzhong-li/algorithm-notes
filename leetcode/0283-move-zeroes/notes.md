# 283. 移动零（Move Zeroes）

- 难度：简单
- 标签：数组、双指针
- 链接：https://leetcode.cn/problems/move-zeroes/

## 题目

给定数组 `nums`，把所有 `0` 移到末尾，其余非零元素保持原来的相对顺序。  
必须**原地**修改，不能复制整个数组。

## 例子

输入：`[0, 1, 0, 3, 12]`  
输出：`[1, 3, 12, 0, 0]`

## 思路（双指针）

这题和哈希表关系不大，核心是**双指针**：

- `fast`：从头到尾扫描每个元素
- `slow`：下一个「非零元素」应该放的位置

规则：

1. `fast` 遇到 `0`：跳过
2. `fast` 遇到非零：和 `nums[slow]` 交换，然后 `slow++`

这样非零会按原顺序被「挤」到前面，零自然被换到后面。

### 走一遍例子

`nums = [0, 1, 0, 3, 12]`，`slow = 0`

| fast | nums[fast] | 操作 | 数组变化 | slow |
|------|------------|------|----------|------|
| 0 | 0 | 跳过 | `[0,1,0,3,12]` | 0 |
| 1 | 1 | 和 slow 交换 | `[1,0,0,3,12]` | 1 |
| 2 | 0 | 跳过 | `[1,0,0,3,12]` | 1 |
| 3 | 3 | 和 slow 交换 | `[1,3,0,0,12]` | 2 |
| 4 | 12 | 和 slow 交换 | `[1,3,12,0,0]` | 3 |

得到答案。

## 另一种写法（先填非零，再补零）

```cpp
int slow = 0;
for (int x : nums) {
    if (x != 0) nums[slow++] = x;
}
while (slow < (int)nums.size()) {
    nums[slow++] = 0;
}
```

意思一样：先把非零按顺序写到前面，剩下位置全填 0。

## 复杂度

- 时间：O(n)，只扫一遍（或两遍）
- 空间：O(1)，原地修改

## 感想 / 踩坑

- 「保持相对顺序」→ 不能乱排序，要用双指针按顺序搬
- 「原地」→ 不要新建一个大数组再拷回去（虽然能过，但不符合题意）
- `slow` 始终指向「已经放好的非零区域」的下一个空位
