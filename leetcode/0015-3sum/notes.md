# 15. 三数之和（3Sum）

- 难度：中等
- 标签：数组、双指针、排序
- 链接：https://leetcode.cn/problems/3sum/

## 题目

给定整数数组 `nums`，找出所有满足下面条件的三元组 `[nums[i], nums[j], nums[k]]`：

- `i`、`j`、`k` 互不相同
- `nums[i] + nums[j] + nums[k] == 0`

答案中不能包含重复的三元组。

## 例子

输入：`nums = [-1, 0, 1, 2, -1, -4]`  
输出：`[[-1, -1, 2], [-1, 0, 1]]`

## 思路（排序 + 双指针）

暴力三重循环是 O(n³)，还要去重，太慢。

标准做法：

1. **先排序**，方便双指针移动，也方便跳过重复
2. 枚举第一个数 `nums[i]`
3. 在 `i` 右边用左右指针找：`nums[left] + nums[right] == -nums[i]`
   - 和太小 → `left++`
   - 和太大 → `right--`
   - 刚好等于 → 记录答案，然后两边都跳过重复值

### 去重要点

| 位置 | 怎么跳 |
|------|--------|
| 第一个数 i | `i > 0 && nums[i] == nums[i-1]` 时 continue |
| left | 找到一组后，`nums[left] == nums[left-1]` 就 ++ |
| right | 找到一组后，`nums[right] == nums[right+1]` 就 -- |

### 优化

若 `nums[i] > 0`，后面全是更大的数，三数之和必 > 0，直接结束。

### 走一遍例子

`nums` 排序后：`[-4, -1, -1, 0, 1, 2]`

| i | nums[i] | left/right 过程 | 找到的三元组 |
|---|---------|-----------------|--------------|
| 0 | -4 | 与右边找和为 4，找不到 | — |
| 1 | -1 | left=2(-1), right=5(2) → 和=0 | `[-1,-1,2]` |
|   |     | left=3(0), right=4(1) → 和=0 | `[-1,0,1]` |
| 2 | -1 | 与 nums[1] 重复，跳过 | — |
| 3 | 0  | 后面找不到和为 0 的两数 | — |

答案：`[[-1,-1,2], [-1,0,1]]`

## 和前面几题的关系

| 题 | 核心 |
|----|------|
| 1 两数之和 | 哈希表找 `target - x` |
| 11 盛水容器 | 左右指针从两端夹 |
| 15 三数之和 | 排序后固定一个数，右边当成「两数之和 = -nums[i]」，用左右指针 |

可以看成：**两数之和的双指针版 + 多一层枚举 + 去重**。

## 复杂度

- 时间：O(n²)（排序 O(n log n)，外层 n，内层双指针 O(n)）
- 空间：O(1) 额外空间（不计答案数组；排序视实现而定）

## 感想 / 踩坑

- 最容易错的是**去重**：三个位置都要处理好，否则会有重复三元组
- 必须先排序，双指针和去重才成立
- 注意 `left` 从 `i + 1` 开始，保证三个下标互不相同
