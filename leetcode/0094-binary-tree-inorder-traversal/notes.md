# 94. 二叉树的中序遍历（Binary Tree Inorder Traversal）

- 难度：简单
- 标签：栈、树、深度优先搜索、二叉树
- 链接：https://leetcode.cn/problems/binary-tree-inorder-traversal/

## 题目

给定二叉树根节点 `root`，返回它的**中序遍历**结果。

## 例子

```text
    1
     \
      2
     /
    3
```

输入：`root = [1,null,2,3]`  
输出：`[1,3,2]`

## 什么是中序遍历？

对每个子树，访问顺序固定为：

```text
左子树 → 根节点 → 右子树
```

三种经典遍历对比：

| 名称 | 顺序 | 记法 |
|------|------|------|
| 前序 | 根 → 左 → 右 | 根在前 |
| **中序** | 左 → 根 → 右 | 根在中 |
| 后序 | 左 → 右 → 根 | 根在后 |

对例子：

1. 根是 1，先走左（没有），访问 1，再走右子树 2  
2. 在节点 2：先走左到 3，访问 3，再访问 2（右空）  

结果：`1, 3, 2`

若是二叉搜索树（BST），中序遍历得到的是**有序序列**。

## 思路一：递归（推荐先掌握）

```cpp
void dfs(TreeNode* node, vector<int>& ans) {
    if (!node) return;
    dfs(node->left, ans);     // 左
    ans.push_back(node->val); // 根
    dfs(node->right, ans);    // 右
}
```

空节点直接返回；否则按「左-根-右」递归。

## 思路二：迭代 + 栈

用栈模拟递归过程：

1. 从当前节点一路向左走，边走边入栈  
2. 走到空后，弹出栈顶并访问（这就是「左完了，访问根」）  
3. 然后转向该节点的右子树，重复  

## 复杂度

- 时间：O(n)，每个节点访问一次  
- 空间：O(h)，h 为树高（递归栈或显式栈）；最坏链状 O(n)

## 感想 / 踩坑

- 二叉树遍历是后面很多题的基础，先把中序递归写熟  
- 空树返回空数组  
- 不要把前/中/后序搞混：看「根」出现在第几个位置
