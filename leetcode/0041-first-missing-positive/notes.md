# 41. 缺失的第一个正数（First Missing Positive）

- 难度：困难
- 标签：数组、哈希表
- 链接：https://leetcode.cn/problems/first-missing-positive/

## 题目

给定未排序整数数组 `nums`，找出其中没有出现的**最小正整数**。

要求：

- 时间 **O(n)**
- 额外空间 **O(1)**（只能用常数额外空间）

## 例子

输入：`nums = [1,2,0]`  
输出：`3`  
解释：`1`、`2` 都在，最小缺失正整数是 `3`。

输入：`nums = [3,4,-1,1]`  
输出：`2`

## 思路（原地哈希 / 把数组当哈希表）

答案一定在 `1 .. n+1` 之间（`n` 为数组长度）：

- 若 `1..n` 都出现了 → 答案是 `n+1`
- 否则答案是 `1..n` 里缺的最小那个

负数、0、大于 `n` 的数对「找 1..n 里缺谁」没有帮助，可以忽略。

不能开一个 `set` / 布尔数组（那是 O(n) 额外空间）。  
做法：**用 nums 自己当哈希表**——

> 理想状态：数字 `x`（若 `1 <= x <= n`）放在下标 `x - 1` 上。  
> 即：`nums[0]=1, nums[1]=2, ..., nums[n-1]=n`（能放的都放对）

### 步骤

1. **置换**：遍历每个位置，若 `nums[i]` 是 `1..n` 且不在正确位置，就把它换到 `nums[i]-1`，直到当前位置对了或不用换。
2. **检查**：从左扫，第一个满足 `nums[i] != i+1` 的，答案就是 `i+1`。
3. 若全都对上，返回 `n+1`。

### 走一遍例子

`nums = [3,4,-1,1]`，`n=4`，关心的是把 1,2,3,4 放到下标 0,1,2,3。

| 操作（示意） | 数组变化 |
|--------------|----------|
| 3 应在下标 2，与 -1 交换 | `[-1,4,3,1]` |
| 4 应在下标 3，与 1 交换 | `[-1,1,3,4]` |
| 1 应在下标 0，与 -1 交换 | `[1,-1,3,4]` |
| 下标 1 是 -1，不用再换 | `[1,-1,3,4]` |

检查：`nums[0]=1` OK，`nums[1]=-1 != 2` → 答案 **2**。

### 和普通哈希的关系

| 做法 | 空间 |
|------|------|
| `unordered_set` 存所有数再查 1,2,3... | O(n) 额外空间，不符合题意 |
| 把 `x` 放到下标 `x-1` | O(1) 额外空间，数组本身当表 |

## 代码对应

```cpp
while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
    swap(nums[i], nums[nums[i] - 1]);
}
```

- 在 `1..n` 内才换  
- `nums[nums[i]-1] != nums[i]` 避免死循环（已经有正确的数占着，或重复数字）

```cpp
if (nums[i] != i + 1) return i + 1;
return n + 1;
```

## 复杂度

- 时间：O(n)，每个数最多被换到正确位置一次
- 空间：O(1) 额外空间

## 感想 / 踩坑

- 答案范围只会是 `1 .. n+1`
- 必须用 `while` 换到位，只 `if` 换一次可能不够
- 判断 `nums[nums[i]-1] != nums[i]` 防止重复值死循环
- 会修改原数组；若题目不允许改，需先说明（LeetCode 一般允许）
