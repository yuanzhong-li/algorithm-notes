# 73. 矩阵置零（Set Matrix Zeroes）

- 难度：中等
- 标签：数组、哈希表、矩阵
- 链接：https://leetcode.cn/problems/set-matrix-zeroes/

## 题目

给定 `m × n` 矩阵，若某个元素为 0，则将其所在行和列的所有元素都设为 0。  
要求**原地**修改。

## 例子

输入：
```text
1 1 1
1 0 1
1 1 1
```
输出：
```text
1 0 1
0 0 0
1 0 1
```
因为 `matrix[1][1] == 0`，第 1 行和第 1 列都变成 0。

## 思路

### 为什么不能边扫边改？

如果看到一个 0 立刻把整行整列改成 0，后面扫描时会把「原来不是 0、被你刚改成 0」的格子也当成新的 0，多清很多行/列。

所以要：**先标记哪些行/列需要清零，最后再统一清零**。

### 简单做法（额外 O(m+n) 空间）

开两个数组 `row[m]`、`col[n]`，扫一遍记下哪些行、哪些列有 0，再扫一遍清零。  
正确，但多用了 O(m+n) 空间。

### 进阶：用第一行、第一列当标记（O(1) 额外空间）

矩阵自己的第一行、第一列拿来当「记事本」：

- `matrix[i][0] = 0` 表示第 `i` 行要清零  
- `matrix[0][j] = 0` 表示第 `j` 列要清零  

但第一行/第一列自己可能本来就有 0，会被标记信息覆盖，所以先用两个布尔变量记住：

- `firstRowZero`：第一行原本要不要整行清零  
- `firstColZero`：第一列原本要不要整列清零  

步骤：

1. 检查第一行、第一列，记下两个布尔值  
2. 从 `(1,1)` 开始扫：若 `matrix[i][j]==0`，则标记 `matrix[i][0]=0`、`matrix[0][j]=0`  
3. 再根据标记，把 `(1..m-1, 1..n-1)` 区域该清的清掉  
4. 最后根据两个布尔值，处理第一行、第一列  

### 走一遍例子

```text
1 1 1
1 0 1
1 1 1
```

1. 第一行、第一列本来都没有 0 → `firstRowZero=false`，`firstColZero=false`  
2. 扫到 `matrix[1][1]==0` → 标记 `matrix[1][0]=0`，`matrix[0][1]=0`：

```text
1 0 1
0 0 1
1 1 1
```

3. 根据标记清内部：第 1 行有标记、第 1 列有标记 →

```text
1 0 1
0 0 0
1 0 1
```

4. 第一行/列本身不需要整行整列再清（布尔为 false），结束。

## 复杂度

- 时间：O(m × n)
- 空间：O(1) 额外空间（只用两个 bool）

## 感想 / 踩坑

- 必须先标记再清零，不能边走边改整行整列
- 第一行/列既当数据又当标记，所以要单独用布尔变量保护
- 最后再处理第一行、第一列，顺序不能反
