# 438. 找到字符串中所有字母异位词（Find All Anagrams in a String）

- 难度：中等
- 标签：哈希表、字符串、滑动窗口
- 链接：https://leetcode.cn/problems/find-all-anagrams-in-a-string/

## 题目

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的**字母异位词**的子串，返回这些子串的起始下标（顺序任意）。

字母异位词：字母种类和个数都相同，顺序可以不同。  
例如 `"abc"` 的异位词有 `"abc"`、`"bac"`、`"cba"` 等。

## 例子

输入：`s = "cbaebabacd"`，`p = "abc"`  
输出：`[0, 6]`

- 下标 0 开始的 `"cba"` 是 `"abc"` 的异位词
- 下标 6 开始的 `"bac"` 是 `"abc"` 的异位词

## 思路（固定长度滑动窗口）

异位词子串的长度一定等于 `p` 的长度 `m`。  
所以窗口不用忽长忽短，**始终保持长度为 m**，在 `s` 上往右滑。

怎么判断窗口是不是 `p` 的异位词？

- 对 `p` 统计每个字母出现次数 → `need`
- 对当前窗口也统计 → `window`
- 两个计数数组完全相同 → 是异位词

用长度为 26 的数组即可（题目是小写字母）。

滑动过程：

1. `right` 右移，`s[right]` 进入窗口（对应计数 +1）
2. 当窗口长度将要超过 `m`：把最左边 `s[right - m]` 踢出（计数 -1）
3. 窗口长度刚好为 `m` 时，比较 `window` 和 `need`，相同就把起始下标 `right - m + 1` 记下来

### 和上一题的关系

| 题 | 窗口特点 | 窗口里维护什么 |
|----|----------|----------------|
| 3 无重复最长子串 | 长度可变：有重复就缩左端 | `unordered_set` 存字符 |
| 438 异位词 | 长度固定 = `p.size()` | 字母出现次数数组 |
| 49 异位词分组 | 不是滑窗口 | 排序后的串当 key |

都和「异位词 / 字符统计」有关，这题是在长串里用窗口找。

### 走一遍例子

`s = "cbaebabacd"`，`p = "abc"`，`m = 3`  
`need`：a=1, b=1, c=1

| right | 进入 | 离开 | 窗口 | 是否匹配 | 记录 |
|-------|------|------|------|----------|------|
| 0 | c | — | `c` | 未满 | |
| 1 | b | — | `cb` | 未满 | |
| 2 | a | — | `cba` | ✓ | 0 |
| 3 | e | c | `bae` | ✗ | |
| 4 | b | b | `aeb` | ✗ | |
| 5 | a | a | `eba` | ✗ | |
| 6 | b | e | `bab` | ✗ | |
| 7 | a | b | `aba` | ✗ | |
| 8 | c | a | `bac` | ✓ | 6 |
| 9 | d | b | `acd` | ✗ | |

答案：`[0, 6]`

## 复杂度

- 时间：O(n)，n 为 `s` 长度；每次比较两个长度 26 的数组可视为 O(1)
- 空间：O(1)，两个大小为 26 的计数数组

## 感想 / 踩坑

- 异位词 → 比的是**计数**，不是字符顺序
- 窗口长度固定时，左端离开位置是 `right - m`，起始下标是 `right - m + 1`
- `s` 比 `p` 短时直接返回空
