# 1. 两数之和（Two Sum）

- 难度：简单
- 标签：数组、哈希表
- 链接：https://leetcode.cn/problems/two-sum/

## 题目

给定整数数组 `nums` 和目标值 `target`，在数组中找出和为 `target` 的两个数，返回它们的下标。  
每种输入只会对应一个答案，同一个元素不能使用两遍；答案可以按任意顺序返回。

## 思路

暴力做法是两重循环，时间 O(n²)。

更优做法：用哈希表边遍历边查。

1. 扫到当前数 `nums[i]` 时，算还需要多少：`need = target - nums[i]`
2. 如果 `need` 已经在哈希表里，说明之前见过配对的数，直接返回两个下标
3. 否则把 `nums[i]` 和下标 `i` 存进哈希表，继续往后扫

只扫一遍数组，每个数查一次表。

## 复杂度

- 时间：O(n)
- 空间：O(n)（哈希表最坏存 n 个元素）

## 感想 / 踩坑

- 这题是哈希表「空间换时间」的经典入门题
- 注意是返回**下标**，不是返回数值本身
- 不能先把整个数组放进哈希表再找（如果有重复值会踩坑）；边走边存更稳妥
- LeetCode 保证一定有解，所以循环结束一般不会走到空返回
