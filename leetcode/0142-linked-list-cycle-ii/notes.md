# 142. 环形链表 II（Linked List Cycle II）

- 难度：中等
- 标签：哈希表、链表、双指针
- 链接：https://leetcode.cn/problems/linked-list-cycle-ii/

## 题目

给定链表头节点 `head`，返回**链表开始入环的第一个节点**。无环则返回 `null`。  
不允许修改链表。

## 例子

输入：`head = [3,2,0,-4]`，`pos = 1`  
环从节点 `2`（下标 1）开始 → 返回该节点。

## 思路（Floyd：先相遇，再找入口）

和 141 的关系：

| 题 | 问什么 |
|----|--------|
| 141 | 有没有环？ |
| **142** | 环从哪开始？ |

### 第 1 步：快慢指针找相遇点

和 141 一样：`slow` 走 1 步，`fast` 走 2 步，有环则相遇。

### 第 2 步：找入口

相遇后：

1. 一个指针放回 `head`  
2. 另一个停在相遇点  
3. **两个都一次走一步**，再次相遇的地方就是**环的入口**

### 为什么对？（简单记）

设：

- 头到入口距离 = `a`
- 入口到相遇点距离 = `b`
- 环长 = `c`

可以推出：从 head 走 `a` 步，和从相遇点再走，会在入口碰头。  
不必死记公式，记住结论即可：**相遇后，一头一相遇点同步走，再相遇 = 入口**。

### 图示

```text
head ----a----> 入口 ----b----> 相遇点
                 ↑               |
                 |-------环------|
```

### 哈希表写法（更好懂）

```cpp
unordered_set<ListNode*> seen;
while (head) {
    if (seen.count(head)) return head;  // 第一次重复出现的就是入口
    seen.insert(head);
    head = head->next;
}
return nullptr;
```

空间 O(n)；快慢指针空间 O(1)。

## 代码对应

```cpp
// 相遇后
ListNode* p = head;
while (p != slow) {
    p = p->next;
    slow = slow->next;
}
return p;
```

## 复杂度

- 时间：O(n)
- 空间：O(1)（快慢指针）

## 感想 / 踩坑

- 先判有没有环，无环直接 `nullptr`
- 找入口时两边都是**一次一步**（不是快慢了）
- 返回的是节点指针，不是下标 `pos`
