# 142. 环形链表 II（Linked List Cycle II）

- 难度：中等
- 标签：哈希表、链表、双指针
- 链接：https://leetcode.cn/problems/linked-list-cycle-ii/

## 题目

给定链表头节点 `head`，返回**环的入口节点**；若无环，返回 `null`。  
不能修改链表。

和 141 的差别：141 只问「有没有环」；这题还要「环从哪开始」。

## 例子

`3 -> 2 -> 0 -> -4`，`-4` 指回 `2` → 入口是节点 `2`。

## 思路（Floyd：两阶段）

### 第一阶段：和 141 一样，快慢指针找相遇点

- `slow` 走 1 步，`fast` 走 2 步  
- 相遇 → 有环；`fast` 走到空 → 无环，返回 `null`

### 第二阶段：找入口（关键）

相遇后：

1. 新指针 `p` 从 `head` 出发  
2. `slow`（或 `fast`）从**相遇点**出发  
3. 两人每次都走 **1 步**  
4. 再次相遇的地方，就是**环入口**

### 为什么第二次相遇就是入口？（详细推导）

先把三段路标清楚：

```text
头 ——L——→ 入口 E ——a——→ 相遇点 M
              ↑                    |
              └—————— b ——————————┘
                      （环上剩下的部分）
```

| 符号 | 含义 |
|------|------|
| `L` | 从头到入口 E 的距离 |
| `a` | 从入口 E 沿环走到第一次相遇点 M 的距离 |
| `C` | 整个环的长度 |
| `b` | 从 M 再走回 E 的距离，且 `C = a + b` |

#### 1. 第一次相遇时，两人各走了多远？

慢指针进环后走到 M，总共走了：

```text
慢指针路程 = L + a
```

快指针速度是慢指针的 2 倍，所以：

```text
快指针路程 = 2 × (L + a)
```

快指针也是先走 `L` 到入口，再在环里转；可能多绕了 `n` 整圈，最后也停在 M：

```text
快指针路程 = L + a + n×C
```

#### 2. 列出方程并化简

```text
2(L + a) = L + a + nC
⇒ 2L + 2a = L + a + nC
⇒ L + a = nC          （两边减去 L+a）
⇒ L = nC - a
```

#### 3. `nC - a` 是什么意思？

从相遇点 M 走到入口 E，最短走 `b = C - a` 步；  
多绕整圈也能到：`b`、`b+C`、`b+2C`… 也就是 `nC - a`。

所以：

```text
L = nC - a = 「从相遇点 M 走到入口 E 的距离」
```

也就是：

> **从头走到入口的步数 L**  
> **等于**  
> **从相遇点走到入口的步数**

#### 4. 对应到第二阶段代码

- 指针 `p` 从 `head` 出发，每次走 1 步 → 走 `L` 步到入口  
- 指针 `slow` 从相遇点出发，每次走 1 步 → 也走 `L` 步到入口  

两人同步走，再次相遇的点就是入口。

#### 5. 数字验算一例

设 `L = 3`，`C = 4`，`a = 1`：

```text
L + a = 4 = 1×C
⇒ L = C - a = 3
```

从相遇点沿环走 `C-a=3` 步回到入口；从头走 `3` 步也到入口。一致。

#### 口诀

记不住公式也行，先记住结论：

> **相遇后，一个回起点，两个各走一步，再相遇就是入口。**

### 走一遍例子

```text
3 → 2 → 0 → -4
    ↑_________|
入口是 2
```

1. 快慢指针在环上某点相遇（比如在 `0` 或 `-4` 等）  
2. `p` 从 `3` 出发，`slow` 从相遇点出发，一步一步走  
3. 两人在 `2` 相遇 → 返回 `2`

## 代码对应

```cpp
ListNode* slow = head;
ListNode* fast = head;
while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;
    if (slow == fast) {
        ListNode* p = head;
        while (p != slow) {
            p = p->next;
            slow = slow->next;
        }
        return p;
    }
}
return nullptr;
```

## 和 141 的关系

| 题 | 问什么 | 做法 |
|----|--------|------|
| 141 | 有没有环 | 快慢指针是否相遇 |
| **142** | 环入口在哪 | 相遇后再从 head 同步走一步 |

## 复杂度

- 时间：O(n)
- 空间：O(1)

哈希表做法：把见过的节点放进 set，第一次重复出现的就是入口，空间 O(n)。

## 感想 / 踩坑

- 第一阶段必须先确认相遇，再找入口  
- 第二阶段两个指针都走 **1 步**（不是一个走两步）  
- 无环时返回 `nullptr`  
- 比的是节点地址相同，不是 `val` 相同
