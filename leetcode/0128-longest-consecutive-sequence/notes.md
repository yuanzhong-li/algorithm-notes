# 128. 最长连续序列（Longest Consecutive Sequence）

- 难度：中等
- 标签：哈希表、数组、并查集
- 链接：https://leetcode.cn/problems/longest-consecutive-sequence/

## 题目

给定未排序整数数组 `nums`，求其中数字能构成的**最长连续序列**的长度。  
要求算法时间复杂度为 **O(n)**。

连续序列指数值连续，例如 `[1,2,3,4]`，不要求在原数组中相邻。

## 例子

输入：`nums = [100, 4, 200, 1, 3, 2]`  
最长连续序列是 `[1, 2, 3, 4]`，长度 `4`。

## 思路

先把所有数放进 `unordered_set`（哈希集合）：

- 作用：快速问「某个数在不在？」
- 顺便去重（重复数字不影响连续序列长度）

关键技巧：不要从每个数都往两边扩（会重复计算，容易变慢）。

只从**一段的起点**开始数：

> 如果 `x-1` 不在集合里，说明 `x` 是某一段的开头。

然后从 `x` 一直往右找 `x+1, x+2, ...`，数出这一段有多长，取全局最大值。

对例子 `[100,4,200,1,3,2]`：

| 数 x | 有没有 x-1？ | 是否当起点 | 能延伸到 |
|------|--------------|------------|----------|
| 1    | 没有 0       | 是         | 1→2→3→4，长度 4 |
| 2    | 有 1         | 否         | 跳过 |
| 3    | 有 2         | 否         | 跳过 |
| 4    | 有 3         | 否         | 跳过 |
| 100  | 没有 99      | 是         | 只有 100，长度 1 |
| 200  | 没有 199     | 是         | 只有 200，长度 1 |

答案是 4。

## 和前两题的关系

| 题 | 用什么 | key / 作用 |
|----|--------|------------|
| 1 两数之和 | `unordered_map` | key=数字，value=下标 |
| 49 异位词分组 | `unordered_map` | key=排序串，value=一组词 |
| 128 最长连续序列 | `unordered_set` | 只关心「数在不在」，不需要 value |

`unordered_set` 可以想成「只有 key、没有 value 的哈希表」，专门做存在性判断。

## 复杂度

- 时间：O(n)。每个数最多被当作起点扩展一次（内层 while 总体不会超过 O(n)）
- 空间：O(n)，存哈希集合

## 感想 / 踩坑

- 先排序再扫也能做，但是排序是 O(n log n)，不满足本题 O(n) 要求
- 一定要用「只从起点开始」这个剪枝，否则容易超时
- 空数组时 `best` 初始为 0，直接返回即可
