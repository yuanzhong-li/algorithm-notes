# 102. 二叉树的层序遍历（Binary Tree Level Order Traversal）

- 难度：中等
- 标签：树、广度优先搜索、二叉树
- 链接：https://leetcode.cn/problems/binary-tree-level-order-traversal/

## 题目

给定二叉树根节点 `root`，返回其节点值的**层序遍历**（逐层，从左到右）。

## 例子

```text
      3
     / \
    9  20
      /  \
     15   7
```

输出：`[[3], [9,20], [15,7]]`

## 思路（BFS + 队列）

层序 = 一层一层往下扫，用**队列**：

1. 根入队  
2. 每次先记下当前队列长度 `sz`（就是这一层的节点数）  
3. 弹出 `sz` 个节点，把值放进本层数组；同时把它们的左右孩子入队（下一层）  
4. 本层数组加入答案，重复直到队列空  

关键：用 `sz` 把「当前层」和「下一层」隔开，否则分不清层与层的边界。

### 走一遍例子

| 步骤 | 队列（示意） | 本层取出 | 答案 |
|------|--------------|----------|------|
| 开始 | [3] | | |
| 第1层 | 取出 3，入队 9,20 | [3] | `[[3]]` |
| 第2层 | 取出 9,20，入队 15,7 | [9,20] | `[[3],[9,20]]` |
| 第3层 | 取出 15,7 | [15,7] | `[[3],[9,20],[15,7]]` |

### 和 DFS（前/中/后序）的区别

| | DFS（94 中序等） | BFS（本题） |
|--|------------------|------------|
| 结构 | 栈 / 递归 | **队列** |
| 顺序 | 纵深优先 | **一层一层** |

## 代码对应

```cpp
int sz = q.size();           // 本层人数
for (int i = 0; i < sz; ++i) {
    TreeNode* node = q.front(); q.pop();
    level.push_back(node->val);
    if (node->left) q.push(node->left);
    if (node->right) q.push(node->right);
}
ans.push_back(level);
```

## 复杂度

- 时间：O(n)
- 空间：O(n)，队列最宽一层

## 感想 / 踩坑

- 一定要先存 `sz`，再 for 循环；边弹边入队时 `q.size()` 会变，不能直接当循环次数
- 空树返回空数组
- 层序是后面很多题的基础（锯齿层序、每一层平均值等）
