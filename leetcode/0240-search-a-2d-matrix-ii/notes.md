# 240. 搜索二维矩阵 II（Search a 2D Matrix II）

- 难度：中等
- 标签：数组、二分查找、分治、矩阵
- 链接：https://leetcode.cn/problems/search-a-2d-matrix-ii/

## 题目

编写一个高效算法，在 `m × n` 矩阵 `matrix` 中搜索目标值 `target`。矩阵具有以下特性：

- 每行从左到右升序
- 每列从上到下升序

## 例子

输入：
```text
1   4   7  11  15
2   5   8  12  19
3   6   9  16  22
10 13  14  17  24
18 21  23  26  30
```
`target = 5` → 返回 `true`  
`target = 20` → 返回 `false`

## 思路（从右上角开始的「楼梯」搜索）

暴力是 O(mn)。更好的办法：从**右上角** `(0, n-1)` 出发。

为什么选右上角？看当前位置 `matrix[x][y]`：

| 比较 | 该怎么走 | 原因 |
|------|----------|------|
| `== target` | 找到了 | 直接返回 true |
| `> target` | **往左** `--y` | 这一列下面的数只会更大，更不可能；左边更小 |
| `< target` | **往下** `++x` | 这一行左边的数只会更小，更不可能；下面更大 |

每一步排除一行或一列，像下楼梯一样走，直到找到或走出边界。

也可以从**左下角**出发，逻辑对称（大了往上，小了往右）。

### 走一遍例子（找 5）

从右上角 `15` 开始：

```text
15 > 5 → 左
11 > 5 → 左
7  > 5 → 左
4  < 5 → 下
5  == 5 → 找到
```

### 为什么正确？

在右上角时：

- 当前列下方都 ≥ 当前值：若当前已大于 target，整列都可以扔
- 当前行左方都 ≤ 当前值：若当前已小于 target，整行左边都可以扔（应往下找更大的）

所以每次决策都安全地缩小搜索范围。

## 代码

```cpp
int x = 0, y = n - 1;
while (x < m && y >= 0) {
    if (matrix[x][y] == target) return true;
    if (matrix[x][y] > target) --y;
    else ++x;
}
return false;
```

## 复杂度

- 时间：O(m + n)。`y` 最多减 n 次，`x` 最多加 m 次
- 空间：O(1)

## 感想 / 踩坑

- 不要从左上角开始：左上角右边更大、下边也更大，无法唯一决定往哪走
- 右上角（或左下角）才能「一大一小」两个方向，每步排除一行或一列
- 空矩阵注意特判（本题一般保证非空，写的时候可按需加）
