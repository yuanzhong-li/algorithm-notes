# 25. K 个一组翻转链表（Reverse Nodes in k-Group）

- 难度：困难
- 标签：递归、链表
- 链接：https://leetcode.cn/problems/reverse-nodes-in-k-group/

## 题目

给你链表头节点 `head`，每 `k` 个节点一组进行翻转，返回修改后的链表。  
`k` 是正整数，且 ≤ 链表长度。  
如果最后剩余节点不足 `k` 个，**保持原顺序**。  
必须实际交换节点，不能只改 `val`。

## 例子

输入：`head = [1,2,3,4,5]`，`k = 2`  
输出：`[2,1,4,3,5]`

```text
(1,2) 翻转 → 2→1
(3,4) 翻转 → 4→3
剩下 5 不足 2 个 → 不动
```

输入：`k = 3` → `[3,2,1,4,5]`（只翻转前三个）

## 思路（dummy + 分组翻转）

可以看成 24「两两交换」的升级：24 是 `k=2`，这题是任意 `k`。

步骤循环：

1. **从上一组尾巴 `prev` 往后数 k 个**，够不够  
   - 不够 → 结束，后面原样留下  
   - 够 → 这一组是 `[groupHead ... kth]`，下一组开头是 `groupNext`
2. **把这一组内部翻转**（和 206 反转链表一样）
3. **接回前后**：`prev→新组头`，`新组尾→groupNext`
4. `prev` 移到本组新尾巴，继续下一组

用 `dummy` 接在最前面，第一组翻转后新头也好处理。

### 图示一组翻转

`k=2`，当前组 `1→2→3...`，`prev` 在 dummy：

```text
翻转前： prev → 1 → 2 → 3...
              groupHead  kth  groupNext

翻转后： prev → 2 → 1 → 3...
                kth  groupHead(现为组尾)
```

### 和前面几题的关系

| 题 | 做什么 |
|----|--------|
| 206 反转链表 | 整条翻转 |
| 24 两两交换 | 每 2 个一组翻转 |
| **25 K 个一组** | 每 k 个一组翻转，不足 k 不动 |

## 代码对应

```cpp
// 数够不够 k 个
ListNode* kth = prev;
for (int i = 0; i < k && kth; ++i) kth = kth->next;
if (!kth) break;

// 翻转 [groupHead, kth]，再接回 prev / groupNext
```

## 复杂度

- 时间：O(n)，每个节点大约被访问常数次
- 空间：O(1)

## 感想 / 踩坑

- 先判断「够不够 k 个」，不够就别翻
- 翻转后记得改三处指针：`prev->next`、组尾的 `next`、以及更新 `prev`
- 再次用到 `dummy`：第一组翻转会换头
