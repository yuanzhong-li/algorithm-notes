# 230. 二叉搜索树中第 K 小的元素（Kth Smallest Element in a BST）

- 难度：中等
- 标签：树、深度优先搜索、二叉搜索树、二叉树
- 链接：https://leetcode.cn/problems/kth-smallest-element-in-a-bst/

## 题目

给定二叉搜索树根节点 `root` 和整数 `k`，返回其中第 `k` 小的元素（`k` 从 1 开始计数）。

## 例子

```text
    3
   / \
  1   4
   \
    2
```

`k = 1` → 最小的是 `1`  
`k = 3` → 从小到大 `1,2,3,...` 第 3 个是 `3`

## 思路（中序遍历）

BST 的中序遍历（左 → 根 → 右）得到的是**从小到大**的序列。

所以：做中序，数到第 `k` 个访问的节点，就是答案。

可以提前结束：找到第 k 个后不再往下递归。

### 走一遍例子

树：`1,2,3,4`，`k=3`

中序访问顺序：`1 → 2 → 3 → 4`  
第 3 个是 `3`。

## 代码逐行讲解

```cpp
int kthSmallest(TreeNode* root, int k) {
    this->k = k;
    dfs(root);
    return ans;
}
```

把 `k` 存成成员变量，方便递归里修改；DFS 后返回答案。

```cpp
int k;    // 还剩几个才数到目标；每访问一个节点减 1
int ans;  // 第 k 小的值
```

```cpp
void dfs(TreeNode* node) {
    if (node == nullptr || k == 0) return;
```

空节点，或已经找到（`k==0`）→ 直接返回（剪枝）。

```cpp
    dfs(node->left);
```

先走左子树（更小的数先被访问）。

```cpp
    if (--k == 0) {
        ans = node->val;
        return;
    }
```

访问当前节点：`--k` 表示又数到一个。  
减完变成 0 → 当前就是第 k 小，记下 `ans`。

例如初始 `k=3`：访问第 1 个后变 2，第 2 个后变 1，第 3 个后变 0 → 命中。

```cpp
    dfs(node->right);
}
```

还没找到就继续走右子树。

也可用栈做迭代中序，同样数到第 k 个。

## 复杂度

- 时间：O(H + k)，H 为树高；最坏 O(n)
- 空间：O(H)

## 感想 / 踩坑

- `k` 从 1 开始：中序访问的第 1 个是最小
- 找到后用 `k==0` 剪枝，避免多余遍历
- 进阶：若频繁查询，可在节点上维护子树大小做二分（本题一次查询用中序即可）
